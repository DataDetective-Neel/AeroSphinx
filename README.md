# AeroSphinx

Reproducible research pipeline for the chapter:

**A Multi-Source Machine Learning Framework for Satellite-Fused PM2.5 Estimation and Five-Day Atmospheric Forecasting over Urban India**

## Current Scientific Status

The repository contains CPCB hourly PM2.5 observations for Faridabad from 2016-2024, local INSAT AOD HDF5 granules for part of 2024, and local NASA MERRA-2 NetCDF files for part of 2024.

The strict multi-source pipeline does **not** fabricate unavailable data. Because historical AOD/MERRA-2 files are not present for 2016-2023 and the available MERRA-2 files do not contain `PBLH`, the preferred 2016-2022 train, 2023 validation, 2024 test split cannot be executed for the full requested feature set. The executable benchmark therefore uses a chronological fallback split over the complete 2024 multi-source window and reports the missing variables in `results/audit_report.md`.

## Project Structure

```text
data/       CPCB hourly PM2.5 CSV files
scripts/    Reproducible pipeline entry point
models/     Trained model artifacts generated by the pipeline
results/    Metrics, predictions, feature ranking, and audit report
figures/    Publication-supporting diagnostic figures
```

Legacy exploratory notebooks, duplicate scripts, and demo app code remain in the repository for audit traceability, but publication metrics should come from `scripts/run_research_pipeline.py`.

## Method

The pipeline:

1. Aggregates CPCB hourly PM2.5 observations to daily means with a minimum-hours quality screen.
2. Extracts station-window INSAT AOD from HDF5 granules and filters fill/invalid values.
3. Extracts available MERRA-2 daily meteorology from NetCDF files.
4. Builds leakage-safe features:
   `AOD`, `T2M`, `TS`, `QV2M`, `U10M`, `V10M`, `SLP`, `Temp_Diff`, `Humidity_Ratio`, `PM25_Lag_1`, `PM25_Lag_2`, `PM25_Lag_3`, `day_sin`, `day_cos`, `month_sin`, `month_cos`.
5. Excludes unavailable `PBLH` empirically and records that as a scientific issue.
6. Trains Random Forest and XGBoost regressors with validation-based hyperparameter tuning.
7. Evaluates Random Forest, XGBoost, and `0.6 * RF + 0.4 * XGB`.
8. Computes MAE, RMSE, R2, and Indian PM2.5 AQI-category accuracy.
9. Generates a true recursive five-day forecast where Day 2+ lag inputs use previous predictions.

## Setup

```powershell
python -m pip install -r requirements.txt
```

If you want to keep dependencies local to the repository:

```powershell
python -m pip install --target .codex_deps -r requirements.txt
```

The script automatically uses `.codex_deps` when that folder exists.

## Run

```powershell
python scripts\run_research_pipeline.py
```

Optional arguments:

```powershell
python scripts\run_research_pipeline.py --min-hours 18 --data-dir data --merra-dir "ML model\merra_downloads" --aod-dir "ML model\aod_folder" --aod-dir "AOD daata"
```

## Empirical Baseline From Current Local Data

The latest completed run used a fallback chronological split:

- Train: 2024-01-07 to 2024-04-13, n=83
- Validation: 2024-04-15 to 2024-05-17, n=28
- Test: 2024-05-18 to 2024-06-18, n=28

Weighted ensemble test metrics:

- MAE: 36.367
- RMSE: 42.213
- R2: -2.146
- AQI-category accuracy: 0.214

These metrics are intentionally not framed as strong performance claims. They are a limited strict multi-source benchmark from the currently available files.
