# Documentation

Two kinds of document live here, and the distinction matters: a **reference**
is authoritative for the current code, a **report** is a dated record that is
never rewritten.

## Figures and screenshots

`figures/` holds the chapter figures, regenerated by
`legacy/aerosphinx_pipeline.py`.

`screenshots/` holds dashboard captures from before the 2026-11-23 redesign
(layout, type and bundle have all changed since), so they are out of date by
design of the turn: the live application at
[aerosphinx.onrender.com](https://aerosphinx.onrender.com) is the reference, and
every number on every panel is reproducible from `results/`.

## Adding a document

* New specification or register → `reference/`, and add it to the table above.
* New phase or experiment report → `reports/`, dated in the title.
* Every relative link is checked by `make check-docs` in CI.
